VisManager Web

Review a folder of images, keep the good ones, and export the result. Files are read as copies — nothing on your disk is changed.

Supported

PNG, JPEG, GIF, WebP, BMP and PDF render natively. TGA is decoded in-page. Cube files are listed but not rendered in the web version — use the desktop app for 3D.
